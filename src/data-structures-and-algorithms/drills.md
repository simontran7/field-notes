## Dynamic Programming

### Prefix          `dp[i]`          (prefix of 1 sequence)
### Value           `dp[v]`          (amount)
### Prefix pair     `dp[i][j]`       (prefix of two distinct sequences)
### Range           `dp[i][j]`       (slice `i..=j` in a sequence)
### Cell            `dp[r][c]`       (cell in a matrix)

- [118. Pascal's Triangle](https://leetcode.com/problems/pascals-triangle/description/)

### Subset          `dp[mask]`       (subset of items)
### Node            `dp[node]`       (node in a graph or tree)
### Capacity        `dp[i][w]`       (prefix and remaining capacity)
### Count           `dp[i][k]`       (prefix and number used)
### Mode            `dp[i][m]`       (prefix and mode/flags)
### Digit           `dp[pos][...]`   (position in a number)
